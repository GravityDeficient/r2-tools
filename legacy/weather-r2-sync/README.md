# Superseded weather R2 sync prototype

This directory preserves the full history and final tree of the former
`GravityDeficient/weather-r2-sync` repository for provenance only.

It is **not deployable or supported**. Do not build its Dockerfile, run its
Compose file, copy its environment example, or reference this path from
MissionControl. The maintained replacement is [`../../sync/`](../../sync/),
which provides validated configuration, retention strategies, structured
logging, tests, and pinned production images.

The files beside this notice intentionally remain unchanged from the imported
repository so the original tree can be verified against commit `e0ee000`.
